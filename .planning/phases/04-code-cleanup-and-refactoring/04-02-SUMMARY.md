## Decisions Made
- Config classes kept as POJOs (not converted to interfaces) because consumers use getters generated by Lombok @Data. Infrastructure extends them with @ConfigurationProperties.
- HelpApp and AppRegistry had @Autowired @Lazy fields — converted to constructor parameters registered via @Bean. No @Lazy needed since all beans are eagerly created in DomainServiceConfig.
- @Async removed from BashApp.executeCommandAsync and OpenCodeTaskExecutor.executeAsync. These methods still function but run synchronously unless wrapped at the infrastructure/app layer.
