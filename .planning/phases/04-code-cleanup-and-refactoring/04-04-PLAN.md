    **Step 4: Refactor OpenCodeCommandHandler as a dispatcher**

    OpenCodeCommandHandler becomes a dispatcher:
    ```java
    public class OpenCodeCommandHandler {
        private final Map<String, SubCommandHandler> handlers;
        private final DefaultHandler defaultHandler;

        public OpenCodeCommandHandler(...) {
            this.handlers = new HashMap<>();
            // Register all handlers with their command names and aliases
            // e.g., handlers.put("connect", connectHandler);
            //       handlers.put("cn", connectHandler);
        }

        public String handle(Message message, String subCommand, String[] args, MessageContext context) {
            SubCommandHandler handler = handlers.get(subCommand);
            if (handler != null) {
                return handler.handle(message, args, context);
            }
            return defaultHandler.handle(message, args, context);
        }
    }
    ```

    Alternatively, if the current code uses a switch, keep a switch but delegate each case to a handler method — the goal is reducing file size, not necessarily introducing a Map-based dispatch. The simplest approach that gets the file under 200 lines is acceptable.
