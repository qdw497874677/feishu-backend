    1. **Remove Spring annotations**: Delete `@Component`, `@Service`, `@Autowired`, `@Lazy` from the class. Do NOT remove `@Slf4j` (Lombok, not Spring).

    2. **Remove Spring imports**: Delete all `import org.springframework.*` lines. This includes:
       - `org.springframework.stereotype.Component`
       - `org.springframework.stereotype.Service`
       - `org.springframework.beans.factory.annotation.Autowired`
       - `org.springframework.context.annotation.Lazy`
       - `org.springframework.scheduling.annotation.Async`
       - Any other `org.springframework.*` imports

    3. **Handle @Async**: `BashApp` uses `@Async("opencodeExecutor")`. Remove the annotation. The async execution should be handled by the infrastructure layer — either wrap the call in an async executor at the app/adapter layer, or accept synchronous execution (simpler for a cleanup phase). If BashApp's async behavior is critical, add `@Bean` wrapping in DomainServiceConfig with async proxy.

    4. **Handle @Lazy**: `HelpApp` and `AppRegistry` use `@Autowired @Lazy`. Since we're removing field injection entirely, these become constructor parameters registered via `@Bean`. No @Lazy needed — all beans are eagerly created in DomainServiceConfig.

    }
